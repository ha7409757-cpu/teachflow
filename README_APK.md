# 📱 TeachFlow Android APK গাইড

আপনার TeachFlow স্কুল ও সিটি ম্যানেজমেন্ট সিস্টেমটি সফলভাবে **Android Native Project** এবং **Debug APK** হিসেবে বিল্ড করা হয়েছে।

---

## 📂 APK ফাইলটি কোথায় আছে?

প্রজেক্টের মূল ডিরেক্টরিতে **`apk-output/`** ফোল্ডারে আপনার APK রাখা আছে:

```
apk-output/
└── app-debug.apk   <-- (আপনার অ্যান্ড্রয়েড APK ফাইল)
```

---

## 📥 কীভাবে পুরো প্রজেক্টের সাথে APK ZIP হিসেবে ডাউনলোড করবেন?

Google AI Studio থেকে APK সহ সম্পূর্ণ প্রজেক্ট ডাউনলোড করতে নিচের সহজ ৩টি ধাপ অনুসরণ করুন:

1. আপনার স্ক্রিনের উপরে-ডানপাশে **Settings (গিয়ার ⚙️ আইকন)** অথবা **মেনু (তিন ডট `...`)** বাটনে ক্লিক করুন।
2. মেনু থেকে **"Export to ZIP"** (বা **"Download ZIP"**) অপশনে ক্লিক করুন।
3. আপনার কম্পিউটারে বা মোবাইলে একটি `.zip` ফাইল ডাউনলোড হবে।
4. জিপ ফাইলটি আনজিপ (Extract) করলেই ভেতরে **`apk-output`** ফোল্ডার পাবেন এবং তার ভেতরে **`app-debug.apk`** ফাইলটি সরাসরি পেয়ে যাবেন!

---

## 🛠️ ভবিষ্যতে পরিবর্তন করলে পুনরায় APK বিল্ড করার নিয়ম:

যদি পরবর্তীতে অ্যাপের কোড পরিবর্তন করেন, টার্মিনালে নিচের কমান্ডটি রান করলেই স্বয়ংক্রিয়ভাবে নতুন APK আপডেট হয়ে যাবে:

```bash
npm run build:apk
```

---

## 📲 সম্পূর্ণ নেটিভ অ্যান্ড্রয়েড সোর্স কোড (Android Studio)

প্রজেক্টের ভেতর **`android/`** ফোল্ডারে সম্পূর্ণ অফিসিয়াল Gradle প্রজেক্ট স্ট্রাকচার তৈরি করে রাখা হয়েছে:
- আপনি চাইলে সরাসরি **Android Studio** ওপেন করে `android/` ফোল্ডারটি ওপেন করতে পারেন।
- সেখানে **Build > Build Bundle(s) / APK(s) > Build APK(s)** চাপলে প্লে-স্টোরের জন্য সাইন্ড রিলিজ APK/AAB ও বিল্ড করে নিতে পারবেন।
